深度学习系统：昇腾技术栈

1. 昇腾计算与软件栈

昇腾 NPU 提供神经网络计算能力。框架通过适配层和 CANN 调用设备，算子开发与推理部署分别面向不同的接口层次。

组件 功能
PyTorch + torch_npu、MindSpore 模型定义、自动微分、训练与框架适配
CANN 图编译、算子、通信、运行与设备调用的基础软件栈
Ascend C 编写运行在 AI Core 上的算子
MindStudio 开发、编译、调试和性能分析
MindSpeed 分布式训练、内存、通信和计算优化
MindIE 模型推理执行与服务

框架提供可组合的计算抽象；编译层把抽象计算映射到硬件；运行时安排资源、内存、同步与通信。模型开发与底层算子开发处于不同抽象层。

2. Cube、Vector 与 Scalar

单元 计算类型
Cube 矩阵乘加和卷积的主体计算
Vector 逐元素运算、激活、归一化等
Scalar 标量计算、寻址、分支与循环控制

计算需要先把数据从外部存储搬入片上存储，再将结果写回。数据复用与搬运效率决定计算单元能否持续得到数据。

3. 多卡互联与训练

HCCS 提供硬件互联，HCCL 提供 AllReduce、Broadcast 等集合通信操作。数据并行、张量并行和流水线并行分别切分样本、层内张量和网络阶段，可以组合使用。

框架构建前向与反向计算，在梯度同步后驱动优化器更新。内存管理、算子调度与并行通信共同影响训练效率。

4. 算子开发与优化

Ascend C 算子一般按 CopyIn → Compute → CopyOut 组织。Tiling 将数据切成适配片上存储的块；双缓冲使当前块计算与下一块搬运重叠。

性能分析需要确认计算、访存、同步或通信中的主导瓶颈。优化收益应通过相同负载下的正确性检查和端到端复测确认。

5. 模型适配与部署

LoRA 冻结原始权重，只训练低秩增量；量化降低权重或激活的位宽，减少存储和搬运。二者分别作用于适配成本与数值表示。

离线推理可采用 ONNX → ATC → OM → AscendCL 路径，ATC 完成图优化和算子映射，msame 可用于离线模型验证。大模型服务可采用框架与 MindIE 的推理路径，两种部署方式的模型格式和运行接口不同。

云、边、端设备的容量、功耗和并发目标不同，需要匹配模型规模、低精度格式与推理配置。
