深度学习系统（二）：神经网络与模型结构

本文最后更新于 2026年10月30日 凌晨

1. 神经网络、反向传播与训练流水线

1.1 从函数到神经网络

神经元将输入加权求和，再经过非线性函数；多层嵌套形成复杂映射。M-P 模型提供了早期抽象，MLP 由输入、隐藏和输出层构成，层间通常全连接。适当条件下、足够宽的非线性网络具有通用逼近能力，这不保证有限数据下容易训练或一定泛化。

模型 主要组织方式或擅长的结构
MLP 全连接特征变换，主要计算是 GEMM
CNN 局部连接与参数共享，处理空间局部结构
RNN / LSTM 隐藏状态随时间传递，处理序列；LSTM 通过门控保留或遗忘信息
GNN 沿图结构组织节点信息的计算

全连接层可写成 Y=XW+b：若 X 为 B×D、W 为 D×D′，输出为 B×D′。矩阵乘（GEMM）是 MLP 的主要计算来源。

监督学习用标签构造目标；无监督学习发现结构，如 K-means、PCA；自监督学习从输入自身构造目标，如 BERT、MAE 的遮挡预测。这是训练信号的分类，与上面的网络结构分类不同。

1.2 反向传播求梯度，优化器更新参数

前向传播逐层计算预测及损失；反向传播从损失出发，沿反向依赖使用链式法则求各参数的梯度；优化器再根据梯度更新参数。

设输出 o 由中间量 a 决定、a 依赖权重 w，Sigmoid 的值为 σ(z)：

\[ \frac{\partial L}{\partial w} =\frac{\partial L}{\partial o} \frac{\partial o}{\partial a} \frac{\partial a}{\partial w},\qquad \sigma'(z)=\sigma(z)(1-\sigma(z)),\qquad w\leftarrow w-\eta\frac{\partial L}{\partial w}. \]

隐藏层同时影响多个下游输出时，需要把各条路径的梯度贡献相加。对 Sigmoid 网络和平方误差，可把课件的逐权重推导压缩成：

\[ L=\frac12\sum_j(o_j-y_j)^2,\quad \delta_j=(o_j-y_j)o_j(1-o_j),\quad \frac{\partial L}{\partial w_{ij}}=h_i\delta_j, \] \[ \delta_i=h_i(1-h_i)\sum_j w_{ij}\delta_j,\qquad \frac{\partial L}{\partial v_{ki}}=x_k\delta_i. \]

这里 w 连接隐藏层与输出层，v 连接输入与隐藏层。先用同一组前向参数算出全部梯度，再更新，不能在求隐藏层梯度时混入已经更新的输出层权重。

课件的两输入、两隐藏、两输出算例中，学习率为 0.5；一次权重更新后，总误差由约 0.2984 降至 0.2910。算例的重点是“输出层局部梯度 → 隐藏层多路径求和 → 负梯度更新”。

误差信号的符号要与更新公式一致：y−prediction 配合加法更新，与 prediction−y 配合减法更新可表示同一负梯度方向。

1.3 为什么加深网络

多层非线性变换组合出层级特征，比只增加单层宽度提供更多组合方式。数据、算力与训练算法共同支撑深层网络；增加层数也会放大梯度传播、优化和泛化的困难。

1.4 训练稳定性：激活、归一化与初始化

  • 梯度消失 / 爆炸：多层导数连乘过小或过大，前层难更新或训练不稳定。
  • 激活函数：Sigmoid、Tanh 有饱和区；ReLU 为 max(0,x)，正区间梯度为 1；Leaky ReLU、PReLU 为负区间保留斜率。
  • 归一化：BatchNorm 使用批次相关统计；LayerNorm 对单个样本 / token 的特征维归一化，帮助控制特征尺度。
  • 初始化：Xavier、He 控制前后层信号尺度，He 常见方差为 2/fan_in。
  • 优化器与学习率：Adam 利用梯度的一阶、二阶矩调节更新尺度；学习率过小收敛慢，过大可能震荡。

1.5 泛化：约束拟合程度

Dropout在训练时随机丢弃部分激活，减少对特定单元的依赖；L1 / L2分别对权重绝对值 / 平方加惩罚；Early Stopping根据验证表现停止训练。它们与解决梯度传播问题的技术属于不同侧重点。

累积 BP 按一组样本汇总梯度。判断过拟合要同时观察训练与验证曲线，数据划分和完整训练流程见第一章。

2. CNN：局部连接、形状推导与矩阵加速

2.1 卷积、激活、池化与全连接

卷积核只看局部区域，并在不同空间位置共享权重；逐层形成从边缘、纹理到高层语义的表示。一次输出是局部输入与核权重逐元素乘后求和，再加偏置。

卷积的形状参数：Kernel 高宽决定局部范围；标准卷积的每个 filter 覆盖全部输入通道；filter 数决定输出通道数；Padding 指边界补值，Stride 指滑动步长。

CNN 中其他层的分工：激活层逐元素加入非线性；最大 / 平均池化做局部聚合和空间下采样；全连接层将特征映射到类别分数。连续线性层仍可合成线性变换，因此需要非线性激活。

分类输出整图类别，检测输出目标类别及位置，分割输出像素类别。共享视觉特征可以服务不同任务头。

不考虑 dilation，核为 Kₕ×K𝑤、输入高宽 H×W、填充 P、步长 S 时：

\[ H_{out}=\left\lfloor\frac{H+2P-K_h}{S}\right\rfloor+1, \quad W_{out}=\left\lfloor\frac{W+2P-K_w}{S}\right\rfloor+1, \quad P_{conv}=C_{out}(C_{in}K_hK_w+1). \]

最后一式含每输出通道一个偏置。例如，输入 [64,3,32,32]、16 个 3×3 核、无填充、步长 1，输出为 **[64,16,30,30]**，参数量 448（不含偏置为 432）。

2.2 LeNet 风格计算流程

下面给出一组 LeNet 风格的卷积网络配置，采用 ReLU 和 MaxPool。

阶段 输出形状
输入 32×32×1
5×5 Conv，6 个核，s=1，p=0；ReLU 28×28×6
2×2 MaxPool，s=2 14×14×6
5×5 Conv，16 个核；ReLU 10×10×16
2×2 MaxPool 5×5×16
Flatten、FC 400 → 120 → 84 → 10

若输入改成 28×28，按同样顺序得到 24→12→8→4，展平维度是 4×4×16=256。

2.3 卷积为什么能转换成 GEMM

直接卷积可用 batch、输出通道、输出高宽、核高宽、输入通道等七重循环表达。卷积通常是典型 CNN 的主要计算来源，其占比取决于具体网络。

im2col 将各滑动窗口展开为列，将卷积核展平为行，再执行高效矩阵乘：若输入通道为 C、核为 R×S、输出空间为 E×F、输出通道为 M，则矩阵形状为 **(M×CRS) · (CRS×EF) = M×EF**，之后 reshape 为特征图。


显式展开会重复存储窗口重叠部分，Implicit GEMM 可避免显式物化整个窗口展开矩阵。

关键系统取舍是：利用成熟 GEMM 的吞吐与数据复用，同时控制显式展开带来的内存和搬运成本。

3. 语言模型、规模化与其他生成模型

语言模型为词元序列建立概率分布，通过上下文预测后续词元。其发展可以按四个阶段理解：

  1. 统计语言模型：N-gram 只看最近 n−1 个词，用频次估计概率；受固定窗口、组合爆炸和数据稀疏限制。
  2. 神经语言模型：Embedding / Word2Vec 把离散词映射为连续向量；RNN 用 h_t=f(x_t,h_{t−1}) 传递历史，LSTM 用门控改善记忆。逐步依赖仍限制并行和长程信息传递。
  3. 预训练语言模型：先在大规模数据上学习表示，再适配下游任务；Transformer 用 Attention 建立 token 间联系，训练中各位置可以并行处理。
  4. 大语言模型：扩展参数、数据和计算，通过提示、指令微调及偏好对齐支持多任务。预训练的“续写能力”与“遵循指令”需要区分。

Scaling Law 是性能与规模之间的经验规律。 “涌现”描述某些任务表现随规模出现明显非线性提升的现象，参数增大并不保证所有任务同步改善。

Transformer 路线 典型模型与用途
Encoder-only BERT、RoBERTa；双向上下文表示、分类与实体识别等
Encoder-Decoder 原始 Transformer、T5、BART；翻译、摘要等序列变换
Decoder-only GPT、LLaMA 等；因果自回归生成

扩散模型训练时逐步加噪、学习反向去噪，生成时从噪声出发恢复图像等内容；CLIP分别编码图像与文本，通过对比学习拉近匹配样本、对齐不同模态的表示。

4. Transformer：从文本到下一个 token

4.1 Tokenizer、Embedding 与位置

文本先经过匹配模型的预处理与分词，得到 token IDs；Embedding 层再查表得到向量。分词可以按词、字符或子词进行：BPE逐步合并常见相邻单元，WordPiece按其词表学习 / 匹配规则形成子词，Unigram从候选词表中筛选子词。词表定义 token 与整数 ID 的对应关系，批次还可能需要 padding 和特殊标记。

Attention 本身不提供位置顺序，需要绝对位置、相对位置或 RoPE 等位置信息。原始正弦位置编码对位置 pos、偶数 / 奇数维度分别使用：

\[ PE_{pos,2i}=\sin\!\left(\frac{pos}{10000^{2i/d}}\right),\qquad PE_{pos,2i+1}=\cos\!\left(\frac{pos}{10000^{2i/d}}\right). \]

d 为表示维度；同一频率的一对正余弦可以用旋转关系表达位置偏移。RoPE 则把 Q、K 的成对维度按位置旋转，使点积体现相对位置。

4.2 Q、K、V 与缩放点积注意力

Q 表示“当前在找什么”，K 表示“可被匹配的信息特征”，V 表示“匹配后要汇总的内容”。自注意力中三者来自同一输入的不同线性投影。

\[ Q=XW_Q,\quad K=XW_K,\quad V=XW_V, \qquad O=\operatorname{softmax}\!\left(\frac{QK^{\mathsf T}}{\sqrt{d_k}}+M\right)V. \]

单头忽略 batch 时，Q、K 的形状为 L×d_k，V 为 L×d_v，注意力分数与权重为 L×L，输出为 L×d_v。L 是序列长度，M 是可选掩码；除以 √dₖ 控制点积尺度，Softmax 按可关注位置归一化。


投影、QKᵀ 与 AV 都涉及矩阵乘法。

多头注意力在不同子空间学习关系，再拼接并投影输出。头可以关注不同信息，但“每个头恰好负责一种固定语义”只是帮助理解的示意。

4.3 Block 的其他部分

特征变换与训练稳定性：FFN 对每个 token 独立执行升维、非线性和降维；残差 x+F(x) 保留直接信息与梯度通路；LayerNorm / RMSNorm 调整特征尺度。

生成约束与输出：因果掩码屏蔽未来位置，允许训练时并行预测各位置的下一个 token；输出线性层把隐藏向量映射成词表 logits，再通过概率与选择策略得到新 token。实际生成仍依赖此前输出，通常逐 token 进行。

原始 Encoder-Decoder 的 Decoder 包含掩码自注意力及对 Encoder 输出的交叉注意力；不能把这种“双注意力”结构直接套到所有 Decoder-only 模型。

关键超参数是层数、隐藏维度、头数、FFN 中间维度和词表大小。Attention、FFN、参数存储和长序列中间张量是主要系统开销来源。MoE、FlashAttention、SSM / Mamba 分别从模型组织、IO 和序列计算等角度改进结构。MoE 用 Router 为每个 token 选择少量 Expert，增加总容量而控制每 token 激活计算，但也带来调度与通信问题。

5. MiniMind：把 Transformer 放到具体模型里

以下是课件中的 MiniMind-3 Dense 示例配置：Decoder-only、64M 参数、8 层、隐藏维度 768；使用 GQA、Pre-Norm + RMSNorm、Q/K 归一化、RoPE 和 SwiGLU，提及 YaRN 位置外推，默认不启用 Dropout。

一次 Block 的主线为：归一化 → Q/K/V 投影与注意力 → 输出投影及残差 → 归一化 → SwiGLU FFN 及残差。

RMSNorm按均方根调整尺度，省去 LayerNorm 的减均值步骤，仍带有可学习缩放。GQA保留较多 Query 头，同时减少 KV 头数，从而减少 KV 存储；逻辑上重复 KV 以匹配 Query 头，不要求缓存物理复制同样的份数。

输入为 [1,29,768] 时：29 个 token，每个 768 维；8 个 Query 头、每头 96 维，拼回输出仍为 [1,29,768]。RoPE 作用于 Q、K 来调整匹配关系，V 保留要汇总的内容。

SwiGLU 将输入分为 Gate 和 Up 两条投影，Gate 经过 SiLU，与 Up 逐元素相乘，再通过 Down 投影并接残差。SiLU 为 z·sigmoid(z)。

固定参数预算时，网络深度与隐藏维度共同决定容量。较深结构可增加特征变换层次，但隐藏维度过窄会限制表示能力。

5.1 训练资源与模型获取

Hugging Face 和 ModelScope 提供模型权重、配置、数据集与相关工具。课件用它们获取 MiniMind；下载权重时还要配套模型结构、Tokenizer 和配置，不能只凭参数文件恢复完整行为。

训练数据路线为 pretrain_t2t → sft_t2t → rlaif/agent_rl，受限资源下用 mini 数据组合或已有权重做实验。
