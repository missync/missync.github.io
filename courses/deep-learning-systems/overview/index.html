深度学习系统（一）：系统组成与执行流程

1. 深度学习系统的组成

深度学习系统是连接算法与硬件的软硬件基础设施，支持模型训练、推理和部署。系统设计同时考虑准确率、时延、吞吐、存储、通信与能耗。

层次 职责
应用与算法 定义任务、模型、损失和优化目标
框架 提供张量、网络层、自动微分和模型训练接口
编译 优化计算图、融合算子、选择实现并生成设备代码
运行时 管理内存、任务队列、同步与通信
硬件 提供计算单元、存储与互联
部署服务 加载模型、处理请求、调度执行并监测运行状态

2. 从模型到执行

一项 AI 任务通常经历输入处理、建模、实现、运行和输出解码。模型层描述计算语义；框架将其展开为算子；编译器与算子库将算子映射为设备 Kernel。

一个算子不一定对应一个 Kernel。 多个算子可以融合为同一 Kernel，一个复杂算子也可能由多个 Kernel 完成。

传统模式识别先提取人工特征再训练分类器；深度学习通过多层网络共同学习特征和预测映射。系统负责把这些计算组织到实际硬件上执行。

3. 算法与系统的协同

模型规模增长会增加计算、参数、激活和通信开销。更少的参数或 FLOPs 不一定意味着更短的实际运行时间，性能还取决于算子实现、数据布局、访存和调度。

系统优化需要先识别瓶颈，再选择算子融合、数据复用、低精度、并行或模型结构调整。优化前后应在相同输入、精度、预热和计时边界下比较正确性与端到端性能。

4. 云、边、端部署

云端通常面向较高并发和吞吐，边缘设备强调靠近数据与低时延，端侧设备还受体积、功耗、内存与离线条件约束。

不同部署位置会影响模型规模、压缩方案、运行时与隐私边界。CPU、GPU、NPU、存储和网络共同构成异构计算平台。
