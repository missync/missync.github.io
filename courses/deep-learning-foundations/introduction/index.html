深度学习基础与应用（一）：机器学习基础

本文最后更新于 2026年10月30日 凌晨

1. AI、ML 与 DL

  • 人工智能（AI）：让机器具备学习、理解、推理、决策、创造和自主行动等能力。
  • 机器学习（ML）：通过数据和经验改善任务表现，是实现 AI 的一类方法。
  • 深度学习（DL）：基于多层人工神经网络进行表征学习，是机器学习的一类方法。

三者的包含关系是 AI ⊃ ML ⊃ DL。神经网络受生物神经系统启发；“深度”指通过多层变换逐步构造表示。

1.1 人工智能的三种思路

  • 符号主义：用符号、规则和逻辑推理表达与处理知识。
  • 连接主义：用相互连接的人工神经元及其连接权重表示和学习知识。
  • 行为主义：强调智能体与环境交互，以及感知、行动和反馈。

1.2 发展脉络

人工神经元模型、Hebb 学习和感知机奠定了早期基础；1956 年达特茅斯会议提出人工智能研究方向。随后，反向传播推动多层网络训练，深层网络与大规模数据、计算资源结合，AlexNet 等模型推动深度学习在视觉识别中的应用。

2. 机器学习学的是什么

机器学习从经验 E 中学习，使任务 T 上以指标 P 衡量的表现得到改善。

以垃圾邮件过滤为例：T 是区分垃圾邮件与正常邮件，E 是用户标注的历史邮件，P 可以是分类正确率。任务、数据和评价指标各有职责。

从函数角度看，机器学习是在寻找 输入 → 输出 的映射。例如，语音识别把声音映射为文字，图像识别把图像映射为类别。

  • 训练（Training）：利用训练数据确定模型参数。
  • 推理（Inference）：使用训练好的模型处理新输入。

3. 四种学习方式

学习方式 主要学习信号
监督学习 带标签的样本，学习输入与目标输出的对应关系
无监督学习 无标签数据，发现数据中的结构或表示
半监督学习 少量有标签数据与大量无标签数据共同参与学习
强化学习 智能体与环境交互，根据奖励学习行动策略

监督学习中，分类预测离散类别，回归预测连续数值。无监督学习可以发现分组或低维结构；强化学习关注行动带来的累积回报。

4. 特征、特征提取与表征学习

特征是用于描述输入、支持任务判断的信息，例如图像的边缘、纹理、形状。特征提取是把原始输入变换为这类表示。

传统方法的流程是：输入 → 人工设计的特征 → 分类或其他任务模型。人工特征依赖经验，难以穷尽复杂场景中的变化；相似的外观特征也可能属于不同类别。

表征学习的流程是：输入 → 学到的特征 → 任务输出。特征提取与任务预测可以放进统一模型中共同训练。

深度网络通过多层变换组合特征：从较局部、简单的模式，逐步得到更抽象的表示。学习表示是深度学习的关键，单纯增加计算步骤并不等于获得有效表示。

5. 深度学习发展的条件

  • 数据：更大的数据集，以及更便利的数据采集和存储。
  • 硬件：GPU、深度学习专用处理器提供训练所需的计算能力。
  • 软件：PyTorch、TensorFlow、PaddlePaddle 等框架支持模型构建与训练。

ImageNet 是大规模视觉数据集；完整数据集与 ILSVRC 图像分类子集要区分。完整 ImageNet 包含超过 1400 万张图像、约 2 万个类别；常用 ILSVRC 分类任务采用 1000 类、约 128 万张训练图像。大规模标注数据使复杂模型的训练和统一评价成为可能。

6. 深度学习的典型任务

6.1 视觉理解：识别内容、位置与关系

任务 要预测的结果
图像分类／识别 图像中的对象类别或身份
目标检测 每个目标的类别与边界框
语义分割 每个像素所属的类别
实例分割 每个目标实例的像素区域，区分同类的不同个体
目标跟踪 目标在连续帧中的位置及身份关联
图像检索 与查询图像相似的图像
生成内容辨别 真实采集或人工生成的判断结果

6.2 视觉生成：合成或转换内容

  • 风格迁移：保留内容图像的主要结构，结合风格图像的外观特征。
  • 图像翻译：把一种图像表示或外观转换为另一种，例如不同图像域之间的转换。
  • 图像合成：根据随机向量或其他条件生成图像；StyleGAN 是生成式模型的例子。
  • 视频合成：生成随时间变化的图像序列，需要兼顾画面内容与时间上的连贯性。

6.3 语言、机器人与科学任务

  • 自然语言处理（NLP）：机器翻译、对话与文本生成；大语言模型用于处理和生成语言。
  • 机器人：把感知结果与行动决策结合，在环境中执行任务。
  • 蛋白质结构预测：根据生物分子信息预测结构，AlphaFold 是代表性应用。

7. 怎样理解模型能力

基准成绩不等于真实场景能力。 应把模型放到与目标用途一致的数据和评价标准下考察。

  • 不同能力分别评价：答对一道题不等于能给出严谨证明；一般视觉问答表现好，也不保证时钟读取、日期推理等细粒度任务可靠。
  • 任务长度与环境影响表现：受控环境中的短任务成功，不代表能稳定完成真实环境中的长程任务。
  • 关注泛化：训练表现好不保证新数据表现好，独立测试与实际部署中的分布变化都需要考虑。
