## 1. 为什么图像处理不必处处全连接

上一章说明了神经网络怎样求梯度和控制过拟合。本章把图像本身的空间结构加入网络设计：**局部连接减少每个位置需要观察的范围，权重共享让同一种模式可以在不同位置被检测。**

### 1.1 全连接层的问题

32×32×3 的彩色图像展开后有 3072 个输入数。若下一层有 1000 个神经元，全连接层就需要 3072×1000 个权重，另加 1000 个偏置。分辨率增大后，参数量增长很快。

展开操作本身不丢掉像素数值，但**全连接层没有显式利用邻近像素之间的空间关系**。图像里的边缘、角点和纹理通常具有局部性，同一种模式也可能出现在不同位置。

| 观察 | 对应设计 | 作用 |
| --- | --- | --- |
| 很多视觉模式只占图像的一小部分 | 局部连接 Local Connection | 每个输出只连接一个局部窗口 |
| 同样的模式会出现在不同位置 | 权重共享 Weight Sharing | 同一卷积核在空间上滑动使用 |
| 复杂形状可由简单模式组合 | 多层特征提取 | 逐层组合局部模式并扩大感受野 |

局部连接本身仍可以让不同位置使用不同权重。**卷积层进一步让这些位置共享同一组权重**，这是参数量显著下降的关键。

### 1.2 空间维度与通道维度

课件按 H×W×C 描述图像：H 为高，W 为宽，C 为通道数。RGB 的 C=3；中间层的通道是网络学到的特征，不再要求具有颜色语义。

一个普通卷积核的形状是 Kₕ×K𝑤×Cᵢₙ，覆盖全部输入通道；在一个空间窗口内做加权求和，再加偏置，得到一个输出数。**一个核形成一张输出特征图，Cₒᵤₜ 个核形成 Cₒᵤₜ 个输出通道。**

![多个卷积核分别生成特征图并沿通道维堆叠](/images/courses/deep-learning-foundations/convolution-feature-maps.png)
*课件第 39 页：32×32×3 输入，6 个 5×5×3 核，无填充、步长 1，得到 28×28×6 输出。*

## 2. 卷积怎样计算：尺寸、参数量与计算量

### 2.1 卷积运算的索引形式

忽略 batch，令输入为 X、权重为 K、偏置为 b；用 s 表示步长、p 表示对称填充，越过原图边界的输入按零填充处理。普通二维卷积层可以写为：

<div class="course-math">
\[
Y_{u,v,o}=b_o+
\sum_{c=0}^{C_{\mathrm{in}}-1}
\sum_{i=0}^{K_h-1}\sum_{j=0}^{K_w-1}
K_{i,j,c,o}\,X_{us+i-p,\,vs+j-p,\,c}.
\]
</div>

深度学习里通常把这种不翻转卷积核的互相关运算也称为“卷积”。不同输出通道有各自的核和偏置，同一输出通道在各空间位置共享它们。

### 2.2 输出尺寸

以下讨论普通卷积，不考虑膨胀卷积与分组卷积。核尺寸为 Kₕ×K𝑤，步长为 s，四周对称填充为 p 时：

<div class="course-math">
\[
H_{\mathrm{out}}=\left\lfloor\frac{H+2p-K_h}{s}\right\rfloor+1,
\qquad
W_{\mathrm{out}}=\left\lfloor\frac{W+2p-K_w}{s}\right\rfloor+1.
\]
</div>

| 输入与设置 | 输出空间尺寸 | 含义 |
| --- | --- | --- |
| 7×7，3×3 核，s=1，p=0 | 5×5 | 边界无法完整放入窗口 |
| 7×7，3×3 核，s=2，p=0 | 3×3 | 更大步长使输出更小 |
| 7×7，3×3 核，s=1，p=1 | 7×7 | 用填充保持高宽 |

课件用“窗口是否整齐落在边界”帮助选择配置。若窗口不能恰好覆盖终点，常见实现按上式向下取整，只使用合法的窗口位置。对于奇数边长核、s=1，取 p=(K−1)/2 可保持空间尺寸；**步长大于 1 时不能直接套用这一结论**。

### 2.3 参数量：与输出空间大小无关

每个输出通道需要 KₕK𝑤Cᵢₙ 个权重和一个偏置，因此：

<div class="course-math">
\[
P_{\mathrm{conv}}=C_{\mathrm{out}}(K_hK_wC_{\mathrm{in}}+1).
\]
</div>

课件的计算题：输入 32×32×3，使用 10 个 5×5 核，s=1、p=2。

- 输出高宽：(32+2×2−5)/1+1=32，因此输出为 **32×32×10**。
- 每个核有 5×5×3=75 个权重，加一个偏置为 76 个参数。
- 总参数量为 **10×76=760**；不含偏置时为 750。

**输入通道决定每个核的深度，输出通道等于核的个数。** 每个核在 32×32 个位置反复使用，参数无需为每个位置重新保存。

### 2.4 参数量少不代表计算量小

同一组权重需要在每个输出位置执行一次。忽略偏置、激活和边界细节，单样本卷积的乘加次数约为：

<div class="course-math">
\[
\mathrm{MACs}=H_{\mathrm{out}}W_{\mathrm{out}}
C_{\mathrm{out}}K_hK_wC_{\mathrm{in}}.
\]
</div>

MAC 表示一次乘加。若分别把一次乘法与一次加法计为一次浮点运算，则 FLOPs 约为 2×MACs，比较数字前应先统一统计口径。

## 3. 1×1 卷积与感受野

### 3.1 1×1 卷积不是只看一个通道

1×1 核没有空间邻域混合，但它覆盖全部输入通道，能在每个像素位置执行同一组通道线性变换：

<div class="course-math">
\[
Y_{u,v,o}=\sum_{c=1}^{C_{\mathrm{in}}}W_{o,c}X_{u,v,c}+b_o.
\]
</div>

例如输入 56×56×64，使用 32 个 1×1 核、s=1、p=0，输出是 56×56×32。空间高宽不变，通道数从 64 降到 32，含偏置参数量为 32×(64+1)=2080。

它既可降通道，也可升通道；配合激活函数还能增加非线性变换。保持空间尺寸依赖步长与填充设置，并非所有 1×1 卷积都保持高宽。

### 3.2 感受野随层数扩大

**感受野 Receptive Field** 是某层一个输出单元在原始输入上可能依赖的区域。一个 3×3 核只观察上一层的 3×3 区域，但上一层每个位置又依赖更早的区域，因此多层叠加会扩大对原图的覆盖。

设第 l 层核边长为 kₗ、步长为 sₗ，rₗ 为理论感受野边长，jₗ 为相邻输出位置在原图上的间距。无膨胀时可递推为：

<div class="course-math">
\[
r_0=j_0=1,\qquad
r_l=r_{l-1}+(k_l-1)j_{l-1},\qquad
j_l=j_{l-1}s_l.
\]
</div>

连续三个 3×3、s=1 的卷积，感受野依次为 3×3、5×5、7×7。若中间加入步长为 2 的下采样，后续一格就对应原图上更大的间距，感受野增长也会更快。

![多层局部连接逐渐扩大对输入的感受范围](/images/courses/deep-learning-foundations/receptive-field.png)
*课件第 69 页：理论感受野说明可能依赖的范围，不代表该范围内每个输入像素的实际影响都同样大。*

卷积的权重共享带来平移等变的倾向：输入模式平移，输出响应也相应移动。边界填充、步长与池化会影响这种关系；**卷积层本身不保证最终分类结果对任意平移都严格不变**。

## 4. 池化层、全连接层与完整 CNN

### 4.1 池化是按通道进行的局部汇总

Max Pooling 取窗口最大值，Average Pooling 取平均值。常见的 2×2、s=2 池化，将高宽各减半，通常保留通道数。

![2×2 最大池化的数值示例](/images/courses/deep-learning-foundations/max-pooling.png)
*课件第 72 页：每个通道独立操作，在每个 2×2 窗口内保留最大值。*

| 层 | 是否通常含可学习参数 | 主要作用 |
| --- | --- | --- |
| Conv | 是 | 学习局部模式与通道组合 |
| 激活函数 | 多数没有，PReLU 等有例外 | 加入非线性 |
| Max / Average Pooling | 否 | 下采样、局部汇总，减少后续开销 |
| FC | 是 | 将特征映射为类别分数等任务输出 |

Max Pooling 反向时把梯度传给前向选中的最大位置；Average Pooling 则按平均规则分配梯度。窗口重叠时，同一输入收到的贡献仍需相加。

### 4.2 一个尺寸变化例子

| 阶段 | 配置 | 输出 H×W×C |
| --- | --- | --- |
| 输入 | RGB 图片 | 32×32×3 |
| Conv + ReLU | 16 个 3×3 核，s=1，p=1 | 32×32×16 |
| MaxPool | 2×2，s=2 | 16×16×16 |
| Conv + ReLU | 32 个 3×3 核，s=1，p=1 | 16×16×32 |
| MaxPool | 2×2，s=2 | 8×8×32 |
| Flatten + FC | 展平后映射为 10 类分数 | 2048 → 10 |

这是为理解尺寸计算构造的示例。**展平维度应从上一层实际输出计算**，输入大小、填充或步长一变，全连接层的输入维度也可能变化。

全局平均池化 GAP 则将每个通道的整个空间取平均，把 H×W×C 变成 C 维向量，再接分类头。它不等于常规 2×2 局部池化，可显著减小分类头的参数量。

## 5. 经典 CNN：每一代主要解决什么问题

| 网络 | 核心设计 | 理解重点 |
| --- | --- | --- |
| AlexNet | 卷积特征提取、ReLU、池化、FC、Dropout，使用 GPU 训练 | 大规模图像分类中深层 CNN 的重要突破 |
| VGGNet | 反复堆叠小尺寸 3×3 卷积 | 用规则结构增加深度 |
| GoogLeNet | Inception 多分支、1×1 降维、GAP | 同时提取多尺度特征并控制计算开销 |
| ResNet | 残差分支与快捷连接相加 | 缓解深层网络的优化退化问题 |
| DenseNet | 把前面各层特征按通道拼接给后层 | 特征复用与更直接的信息传递 |

### 5.1 AlexNet：卷积提特征，FC 做分类

课件采用输入为 227×227×3 的教学配置：第一层 96 个 11×11 核，s=4、p=0，因此输出高宽为 (227−11)/4+1=55，输出为 **55×55×96**。含偏置参数量为：

<div class="course-math">
\[
P=(11\times11\times3+1)\times96=34\,944.
\]
</div>

整个网络包含 5 个卷积层和 3 个全连接层，在若干位置使用最大池化，FC 部分使用 Dropout。学习这类架构时，应先顺着**输入尺寸、输出通道、下采样位置、最终分类头**检查一遍，再计算参数量。

### 5.2 VGG：为什么反复使用 3×3

VGG 的典型做法是使用 3×3、s=1、p=1 卷积保持空间高宽，再用 2×2、s=2 池化下采样。VGG-16 的 16 个带权重层是 13 个卷积层加 3 个全连接层。

假设各层通道数均为 C，忽略偏置：

| 达到的理论感受野 | 一次大核卷积 | 多次 3×3 卷积 |
| --- | --- | --- |
| 5×5 | 25C² 个权重 | 两层：18C² 个权重 |
| 7×7 | 49C² 个权重 | 三层：27C² 个权重 |

小核堆叠在该假设下减少参数，同时能插入更多非线性。**感受野相同不表示计算出的函数相同**，因为中间还增加了特征变换与激活。

课件还强调显存分析。参数存储和激活存储要分开算：一个 N×H×W×C 的 FP32 激活仅数据本体就需 4NHWC 字节；训练还要考虑梯度、保存的中间结果及优化器状态。早期高分辨率激活和末端大型 FC 都可能造成较大开销。

### 5.3 GoogLeNet：多尺度分支与瓶颈层

Inception 模块将同一输入交给并行的 1×1、3×3、5×5 卷积及池化分支，各分支保持相同空间高宽，再沿通道维拼接。

课件中的朴素模块输入为 28×28×256，分支输出通道分别为 128、192、96、256，故拼接后为 28×28×672，总计 526848 个激活值。**这里约 527K 指激活元素数，不是模型参数量。**

直接在 256 个输入通道上执行大核卷积，成本很高。因此先用 1×1 卷积减少通道，再执行 3×3 或 5×5；池化分支之后也用 1×1 控制输出通道。

![在大核卷积前使用1×1瓶颈层的Inception模块](/images/courses/deep-learning-foundations/inception-bottleneck.png)
*课件第 110 页：各分支输出沿通道维拼接，改进模块输出为 28×28×480。*

以 3×3、192 输出通道分支为例，忽略偏置：

<div class="course-math">
\[
P_{\mathrm{direct}}=3\times3\times256\times192=442\,368,
\]
\[
P_{\mathrm{bottleneck}}=1\times1\times256\times64
+3\times3\times64\times192=126\,976.
\]
</div>

1×1 层虽然新增一次计算，却能降低后续大核的成本。原版 GoogLeNet 还通过 GAP 减少末端 FC 开销，并在训练中使用辅助分类器改善中间层监督；推理主要使用最终分类输出。

### 5.4 ResNet：让网络学习残差

课件展示的退化现象是：普通网络加深后，**训练误差也可能升高**。这不能仅用过拟合解释，因为过拟合通常是训练集拟合很好、验证表现变差。

残差块不直接拟合目标映射 H(x)，而是学习 F(x)=H(x)−x，再把输入加回来：

<div class="course-math">
\[
y=x+F(x;W).
\]
</div>

![普通网络块与残差网络块的比较](/images/courses/deep-learning-foundations/residual-block.png)
*课件第 124 页：若所需变换接近恒等映射，残差分支可以学习接近 0 的修正。*

只考虑相加节点、采用列向量梯度记法，反向传播包含一条来自恒等分支的直接贡献：

<div class="course-math">
\[
\nabla_x L=\nabla_y L+J_F(x)^{\mathsf T}\nabla_y L.
\]
</div>

J_F 是残差映射的 Jacobian。若块后还有激活函数，要把其导数继续纳入；恒等路径有助于梯度传播，但不保证任意深度都自动训练成功。

相加要求形状匹配。通道数或空间尺寸改变时，可用投影快捷连接，例如带相应步长的 1×1 卷积，将 x 变为 Wₛx。常见 ResNet-18/34 使用两层 3×3 的基本块，ResNet-50/101/152 使用 1×1、3×3、1×1 的瓶颈块。

课件训练配置还包括 Batch Normalization 与 Kaiming 初始化。这些与残差结构共同帮助深层网络训练；初始化的作用是控制信号尺度，而不是用一个固定权值填满网络。

### 5.5 DenseNet：相加与拼接的区别

DenseNet 将一个 dense block 内前面各层的特征拼接后交给当前层：

<div class="course-math">
\[
x_l=H_l([x_0,x_1,\ldots,x_{l-1}]).
\]
</div>

方括号表示通道拼接。若初始通道为 C₀，每层新增 k 个通道，则 l 层后共有 C₀+lk 个通道，k 称为增长率。Transition layer 在 dense block 之间压缩通道或下采样。

| 连接方式 | 操作 | 对通道的影响 |
| --- | --- | --- |
| ResNet | x+F(x)，逐元素相加 | 相加的两路形状必须匹配 |
| DenseNet | [x₀,x₁,…]，沿通道拼接 | 保留各路特征，通道数累积增长 |

特征复用可以提高参数利用率，但大量特征的保存和拼接也会带来显存、访存开销，不能仅凭参数量判断实际运行成本。

## 6. 迁移学习：按数据量与任务差异决定微调范围

预训练 CNN 的浅层往往包含较通用的边缘、纹理等特征，越靠后的表示通常越贴近预训练任务。迁移学习利用这些已学到的表示，为新任务训练分类头或微调部分网络。

| 目标数据 | 与预训练数据相似 | 与预训练数据差异大 |
| --- | --- | --- |
| 数据较少 | 冻结骨干作特征提取器，主要训练新分类头 | 优先增加数据或合理增强；深层微调更容易过拟合 |
| 数据较多 | 可微调较靠后的若干层 | 可尝试解冻更多层，让特征适应新领域 |

这是课件给出的经验起点，具体解冻范围与学习率仍应由验证集选择。

以原先的 1000 类模型迁移到 10 类为例：

1. 保留预训练特征提取部分，把最终输出层替换为 10 类分类头。
2. 数据少时先冻结骨干，训练新分类头，得到可比较的基线。
3. 若验证表现需要进一步改善，再逐步解冻部分层，通常对预训练部分使用较小学习率。
4. 结合数据增强和验证指标选择训练长度，最后使用独立测试集评价。

**冻结参数与切换训练/评估模式是不同操作。** 冻结决定参数是否参与更新；Dropout 的随机性、BatchNorm 的运行统计还受模式控制。只把参数梯度关掉，不等于所有层的行为都已切换到推理状态。

## 7. 本章计算与概念检查

| 问题 | 检查要点 |
| --- | --- |
| 卷积核的深度是多少 | 普通卷积中等于输入通道数 |
| 输出有多少通道 | 等于卷积核个数，不能遗漏通道维 |
| 参数量要不要乘输出高宽 | 不乘；权重在空间位置间共享 |
| 1×1 卷积能不能提取特征 | 可以混合、压缩或扩展通道 |
| 池化会不会学习一个卷积核 | 常规 Max / Average Pooling 没有这种可学习核 |
| 网络加深后训练误差升高是否必然过拟合 | 还要考虑优化退化 |
| Inception、ResNet、DenseNet 怎样合并分支 | 分别主要使用通道拼接、逐元素相加、跨层通道拼接 |
